# Burhani-Foods-Showcase
Burhani Foods is a full-stack e-commerce web application built with PHP, MySQL, JavaScript, HTML and CSS for a real business. The platform features secure OTP-based authentication, product and variant management, inventory tracking, a cookie-based shopping cart, direct and cart checkout, Cashfree payment gateway integration, automated courier tracking, invoice generation, email notifications, intelligent product search, and a comprehensive admin panel for managing products, orders, and customers. The application emphasizes security, data integrity, and a seamless shopping experience through robust backend validation and transaction-based order processing.

## Features
- Secure OTP-based Authentication
- Customer & Admin Login System
- Product Variant Management
- Inventory & Stock Tracking
- Cookie-based Shopping Cart
- Direct Checkout (Buy Now)
- Cart Checkout
- Cashfree Payment Gateway Integration
- Cash on Delivery (COD)
- Order Management System
- Automated Courier Integration
- Real-time Order Tracking
- Invoice Generation
- Email Notifications
- Product Search
- Customer Management

- Server-side Validation
- Database Transaction Management

This repository is intended as a portfolio showcase for Burhani Foods.

As the application powers a real business, the source code, database design, APIs, and implementation details are kept private to protect proprietary business logic and security.
